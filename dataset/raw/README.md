# Add your labelled portrait images here

Create one folder per class. The folder name becomes the model's label, so use these exact names to connect to the web story profiles:

```text
dataset/raw/
  iron_man/
  spider_man/
  doctor_strange/
  black_panther/
  thor/
  loki/
  black_widow/
  captain_america/
  scarlet_witch/
```

Add clear, front-facing, properly licensed portraits to each folder. Keep classes balanced: aim for at least 300 detected faces per hero and include changes in lighting, age, pose, and expression. Do not include the same still or near-duplicate frames in both training and validation data.
